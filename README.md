- Password and account security administration

## What I Learned

**1. Create a new user and assign a license**
Learned how to provision a new account in the M365 Admin Center and attach the correct license so the user gets access to the right apps and services from day one.

**2. Reset a user's password**
Learned how to reset a user's password as an admin, including how temporary passwords and forced reset-on-login work.

**3. Add a user to a group**
Learned how group membership controls access to shared resources, and how to add users to existing groups through the admin panel.

**4. Disable and delete a user (offboarding)**
Learned the proper offboarding process — disabling an account before deleting it, and why that order matters for data retention and security.

**5. Access Outlook, OneDrive, and Teams settings from the admin panel**
Learned how the admin panel centralizes settings across M365 apps, and how to navigate between service-specific configuration pages.

**6. Change sharing permissions on a OneDrive folder**
Learned how to manage sharing settings on OneDrive folders, including adjusting who has access and at what permission level.
